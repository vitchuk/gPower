# Фича 0001: Русский перевод названий и техники упражнений

## Цель

Пользователь-русскоязычный должен видеть названия и технику упражнений на русском, не теряя исходные английские данные. Дополнительно ассистент должен ссылаться на упражнения русскими названиями.

## Пользовательская ценность

Гость и пользователь читают каталог и ответы ассистента по-русски; поиск лучше находит русские запросы.

## Контракты

Хранение — `data-aug/translations/<id>.json` (клон датасета не трогаем, см. ADR-0006):

```json
{ "id": "Air_Bike", "name": "Air Bike", "nameRu": "Велосипед", "instructionsRu": ["…", "…"] }
```

Изменения в ответах API (`docs/api.md`):

| Где | Новые поля |
|---|---|
| `GET /api/exercises` — `items[]` | `nameRu` (string \| null) |
| `GET /api/exercises/:id` | `nameRu`, `instructionsRu` (string[] \| null) |
| MCP `search_exercises` / `get_exercise` | те же поля (через общий `catalog-core`) |

Инструкция `npm run translations`: генерирует отсутствующие переводы (идемпотентно), требует `DEEPSEEK_API_KEY`.

## Критерии приёмки

- [x] `data-aug/translations/` содержит 876 файлов; у каждого непустой `nameRu`; число `instructionsRu` равно числу EN-шагов (кроме упражнений без EN-шагов — там `[]`)
- [x] Каталог показывает русское название основным, английское — второй строкой
- [x] Страница упражнения: русский заголовок, английский подзаголовок, русские шаги техники
- [x] Поиск находит русские названия и технику
- [x] Ассистент называет упражнения по-русски; в цитатах-карточках русские названия
- [x] `npm run build` проходит

## Проверка

```bash
npm run translations                      # генерация (идемпотентно)
npm run index                             # пересборка индекса (двуязычные документы)
node -e "import('./src/index.js').then(m=>console.log(m.toDetail(m.findExercise('Air_Bike')).nameRu))"  # (workdir: packages/catalog-core)
npm run build
```

## Вне области

Перевод названий фильтров и категорий (уже на русском), озвучка, локаль EN в интерфейсе.
