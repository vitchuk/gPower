# Фича 0003: Табата-таймер с конструктором и созданием через ассистента

## Цель

Добавить вкладку «Табата» с интервальным таймером, в котором пользователь собирает тренировку из упражнений каталога, сохраняет, редактирует и запускает её. Ассистент должен уметь подбирать упражнения под табату: получить запрос («сделай табату из 10 упражнений»), задать уточняющие вопросы, собрать и сохранить табату пользователя.

## Пользовательская ценность

Пользователь перестаёт держать таймер отдельно и вручную подбирать упражнения: он получает готовую, сохранённую табату прямо из диалога с ассистентом и запускает её одним нажатием. Ручной конструктор во вкладке закрывает сценарий «соберу сам».

## Контракты

### Модель табаты

Табата — именованный набор упражнений с общими интервалами:

```json
{
  "name": "Утренняя табата",
  "params": { "prepare": 10, "work": 20, "rest": 10, "rounds": 8, "restBetween": 0 },
  "exercises": [
    { "id": "Pushups", "rounds": null },
    { "id": "Bodyweight_Squat", "rounds": 6 }
  ]
}
```

- `params.prepare` — подготовка, с (0–60), по умолчанию 10
- `params.work` — работа, с (5–600), по умолчанию 20
- `params.rest` — отдых, с (0–300), по умолчанию 10
- `params.rounds` — раундов на упражнение (1–20), по умолчанию 8
- `params.restBetween` — отдых между упражнениями, с (0–300), по умолчанию 0
- `exercises` — 1–20 упражнений; `rounds` — опциональное переопределение раундов (1–20), `null` — брать `params.rounds`
- `name` — 1–80 символов

Длительность (вычисляется): `prepare + Σ(rounds_i · (work + rest)) + (n−1) · restBetween`.

Сервер обогащает каждое упражнение данными каталога при сохранении (`id`, `name`, `nameRu`, `thumbnail`, `gifUrl`) и возвращает их в ответах и в снимке для чата.

### БД (изменения в `docs/data.md`)

| Таблица | Изменение |
|---|---|
| `tabatas` | Новая: `id INTEGER PK AUTOINCREMENT`, `user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE`, `name TEXT NOT NULL`, `params TEXT NOT NULL` (JSON), `exercises TEXT NOT NULL` (JSON), `created_at TEXT NOT NULL DEFAULT (datetime('now'))` |
| `messages` | Новая колонка `tabata TEXT` — JSON-снимок созданных табат в сообщении ассистента (для отображения карточки при перечитывании чата) |

### REST API (изменения в `docs/api.md`)

Все маршруты требуют auth (`401 unauthorized` иначе); ресурс принадлежит пользователю (`404 not_found` для чужого/несуществующего).

| Метод | Путь | Тело | Ответ | Ошибки |
|---|---|---|---|---|
| GET | `/api/tabatas` | — | `{ tabatas: [Tabata] }` (сорт. по id desc) | 401 |
| POST | `/api/tabatas` | `{ name, params, exercises }` | `{ tabata: Tabata }` | 400 `invalid`, 401 |
| GET | `/api/tabatas/:id` | — | `Tabata` | 401, 404 |
| PUT | `/api/tabatas/:id` | `{ name, params, exercises }` | `{ tabata: Tabata }` | 400 `invalid`, 401, 404 |
| DELETE | `/api/tabatas/:id` | — | `{ ok: true }` | 401, 404 |

`Tabata` = `{ id, name, params, exercises, durationSec, created_at }`. `exercises` — обогащённые объекты. Тело POST/PUT принимает `exercises: [{ id, rounds? }]`; неизвестный `id` или выход за лимиты → `400 invalid`.

### SSE (изменения в `docs/api.md`)

| Событие | Payload | Когда |
|---|---|---|
| `tabata` | `{ type: "tabata", tabata: Tabata }` | после генерации ответа, по одному на каждую созданную ассистентом табату; перед `citations` и `done` |

`GET /api/chats/:id/messages`: каждое сообщение получает поле `tabata: Tabata[]` (пустой массив, если нет).

### Ассистент (изменения в `docs/architecture.md`, `docs/api.md`)

- В личных чатах (auth) к набору MCP-инструментов добавляется локальный инструмент `create_tabata` (не часть MCP-сервера; выполняется в `apps/server/src/chat.js` с `user_id` сессии).
- Аргументы: `name`, `exerciseIds[]`, `workSec?`, `restSec?`, `rounds?`, `prepareSec?`, `restBetweenSec?`. Результат для модели — компактный (`id`, `name`, `durationSec`, число упражнений).
- В анонимном `/api/help` инструмент недоступен.
- Системный промпт обязывает ассистента до вызова `create_tabata` задать одним сообщением уточняющие вопросы: длительность всей табаты, сложность упражнений, доступное снаряжение, целевые мышцы; интервалы по умолчанию — классика 20/10 × 8, подготовка 10 с. Упражнения подбираются через `search_exercises`; число упражнений выводится из желаемой длительности. Повторный запрос создаёт новую табату.

### UI (вкладка «Табата»)

- Новый таб «Табата» в шапке, роут `/tabata` (`meta.requiresAuth`).
- Три режима: список сохранённых табат; конструктор (создание/редактирование); плеер.
- Конструктор: название, интервалы, поиск упражнений — кнопка «Фильтры» (`FilterPanel`, сворачиваемый бабл) и поле поиска в одну строку; список результатов с автоподгрузкой следующих страниц при скролле (страницами по 12, `GET /api/exercises`); клик по строке открывает модальное окно с полной карточкой упражнения (`ExerciseDetail`; закрытие — фон, ESC, ✕) и кнопкой «Добавить в табату»; добавление/удаление/перестановка, переопределение раундов, сохранение.
- Плеер: фазы подготовка → работа/отдых по раундам → отдых между упражнениями → финиш; две колонки — слева тайтл, крупные фаза и таймер (`text-6xl`), полосы прогресса фазы и табаты (временнóй прогресс), контролы; справа изображение упражнения. В фазу «работа» показывается фото упражнения (мгновенная смена каждые 1с, без анимации, GIF не используется); в подготовку/отдых/финиш — SVG-заглушка «отдыхающий человек» и название упражнения. При паузе тренировки смена фото останавливается, а блок изображения получает grayscale (эффект заморозки); «Продолжить» снимает фильтр и возобновляет смену. Контролы: пауза/продолжить, «Следующее» (пропуск текущего упражнения без остатка раундов и отдыха — сразу первое действие следующего; в подготовке — пропуск подготовки; прогресс смещается на полное время упражнения + отдых), сброс/заново, выход; звуковые сигналы (WebAudio) на смене фаз и последних 3 секундах; Wake Lock на время выполнения.
- Уход с роута во время выполнения → пауза; возврат продолжает с того же места (состояние в памяти SPA); перезагрузка страницы — сброс.
- Переход из чата: кнопка «Открыть в таймере» на карточке табаты в сообщении ассистента ведёт на `/tabata?open=<id>` и показывает предпросмотр с кнопкой «Старт».

## Критерии приёмки

- [ ] `POST /api/tabatas` с валидным телом возвращает `Tabata` со `durationSec`; невалидные лимиты/id → `400 invalid`; аноним → `401`
- [ ] `GET/PUT/DELETE /api/tabatas/:id` работают только для владельца; чужой id → `404`
- [ ] `GET /api/chats/:id/messages` отдаёт поле `tabata` (массив) для сообщений с созданными табатами
- [ ] Запрос ассистенту «сделай табату» → сначала уточняющие вопросы (длительность, сложность, снаряжение, мышцы), без вызова `create_tabata`
- [ ] После ответов ассистент подбирает упражнения каталога, вызывает `create_tabata`; в чате появляется карточка табаты с рабочей кнопкой «Открыть в таймере»
- [ ] Созданная табата видна во вкладке; её можно редактировать и удалить
- [ ] Ручной конструктор: создать/сохранить/переименовать/изменить интервалы и состав
- [ ] Плеер проходит фазы в верном порядке и длительности, пауза/продолжить/сброс работают, звук звучит на смене фаз
- [ ] Уход с роута во время выполнения ставит на паузу, возврат продолжает; reload сбрасывает
- [ ] `npm run build` проходит
- [ ] `docs/SPEC.md`, `docs/architecture.md`, `docs/api.md`, `docs/data.md` обновлены

## Проверка

```bash
npm run build
curl -i http://localhost:3000/api/tabatas                     # 401 без сессии
curl -b cookie.txt -X POST http://localhost:3000/api/tabatas --data-binary @tabata.json
curl -b cookie.txt http://localhost:3000/api/tabatas
curl -b cookie.txt -X DELETE http://localhost:3000/api/tabatas/1
npm run dev
```

Запросы с кириллицей — через `curl --data-binary @file.json` (UTF-8), см. `docs/pitfalls.md`. Смоук ассистента: залогиниться, написать «сделай табату из 10 упражнений», ответить на вопросы, проверить карточку и вкладку.

## Вне области

- Вибрация, PWA/офлайн/фоновая работа и уведомления.
- История выполненных тренировок, статистика, шеринг табат.
- Не-табата форматы (EMOM, AMRAP), супер-сеты, произвольные типы фаз.
- FR-11 «Программы-тренировки как тип документов» — остаётся планом.
- Интеграция с web5/DWN и кодом референсного `andorsk/web5-tabata-timer` (React/Next.js несовместим; берём только UX-идеи).
