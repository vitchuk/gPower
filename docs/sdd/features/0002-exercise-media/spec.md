# Фича 0002: GIF-анимации и циклическая галерея на странице упражнения

## Цель

Обогатить страницу упражнения анимированной демонстрацией движения (GIF из внешнего датасета) и упростить просмотр фотографий: убрать ленту сабнейлов, оставить одно большое изображение, переключающееся по клику по кругу.

## Пользовательская ценность

Гость и пользователь видят, как выполняется упражнение, не уходя на сторонний сайт; техника читается быстрее. Переключение фото по клику освобождает место и убирает визуальный шум.

## Контракты

### Хранение маппинга (data-aug)

Внешний клон датасета — `cesar-exercises-dataset/` (gitignored; upstream `hasaneyldrm/exercises-dataset`, зеркало `Cesarfc206/exercises-dataset`). Клон не изменяется; обновляется через `git pull` (аналогично `free-exercise-db/`, см. ADR-0006).

Маппинг — `data-aug/media/<id>.json` (версионируется):

```json
{
  "id": "3_4_Sit-Up",
  "name": "3/4 Sit-Up",
  "source": "hasaneyldrm/exercises-dataset",
  "sourceId": "0001",
  "sourceName": "3/4 sit-up",
  "gif": "videos/0001-2gPfomN.gif",
  "thumb": "images/0001-2gPfomN.jpg"
}
```

Ручные правки — `data-aug/media/overrides.json`: `{ "<наш id>": "<sourceId>" | null }` (`null` — подавить автоподбор).

Генератор: `npm run media-map [-- --write] [-- --report=<path>]`. Идемпотентен: пересобирает маппинг из текущих данных датасета, ручные overrides применяются первыми.

### API (изменения в `docs/api.md`)

| Метод | Путь | Изменение |
|---|---|---|
| GET | `/gifs/*` | Новый статический маршрут: GIF из `cesar-exercises-dataset/videos` (`image/gif`) |
| GET | `/api/exercises/:id` | Новое поле `gifUrl` (`string \| null`) — `/gifs/<file>` для сопоставленных упражнений |
| MCP | `get_exercise` | То же поле через общий `catalog-core` (обновить `docs/mcp.md`) |

`GET /api/exercises` (список) не меняется — GIF только на детальной странице.

### UI (страница упражнения)

- Лента сабнейлов удалена.
- Одно большое изображение; при `imageUrls.length > 1` работает автосмена каждые 1с (мгновенная, без анимации; кнопка ▶/⏸ в правом нижнем углу, по умолчанию остановлена) и ручной перебор по клику (`(index + 1) % length`), курсор `pointer`, индикатор `1 / N` в левом нижнем углу.
- При `imageUrls.length === 1` автосмена и клик неактивны; при `0` — заглушка «нет фото».
- При наличии `gifUrl` GIF встроен в блок «Техника выполнения» (`float-left`, текст шагов обтекает справа) с видимой подписью `© Gym visual — https://gymvisual.com/`.

> Обновлено 2026-10-19: автосмена с ▶/⏸; GIF перенесён из отдельного блока «Анимация» в блок техники с обтеканием.

## Измеренное покрытие (2026-10-18)

| Показатель | Значение |
|---|---|
| Упражнений в каталоге | 876 |
| Сопоставлено автоматически (exact 132 + tokenset 65 + fuzzy 26 + override 1) | **224 (25.6%)** |
| Кандидатов на ручной разбор (score 0.6–0.8) | 195 |

Наборы упражнений у датасетов различаются: большинство упражнений каталога не имеет GIF. Это осознанное ограничение, а не дефект; расширяется через `overrides.json`.

## Критерии приёмки

- [ ] `data-aug/media/` содержит 224 файла `<id>.json` + `overrides.json`; формат соответствует контракту
- [ ] `GET /gifs/<file>` отдаёт `200` и `Content-Type: image/gif`
- [ ] `GET /api/exercises/:id` для сопоставленного упражнения содержит `gifUrl`, для несопоставленного — `null`
- [ ] На странице упражнения с GIF: виден анимированный GIF и подпись «© Gym visual — https://gymvisual.com/»
- [ ] Сабнейлы отсутствуют; клик по большому изображению циклически переключает 2 фото
- [ ] При одном фото клик ничего не меняет; при нуле — «нет фото»
- [ ] `npm run build` проходит
- [ ] `docs/api.md`, `docs/data.md`, `docs/mcp.md`, `docs/architecture.md` обновлены

## Проверка

```bash
npm run media-map                                  # пересборка маппинга (идемпотентно), без --write — только отчёт
npm run media-map -- --write                       # записать data-aug/media/*.json
curl http://localhost:3000/api/exercises/3_4_Sit-Up   # ожидается gifUrl
curl -I http://localhost:3000/gifs/0001-<mediaId>.gif # 200, image/gif
npm run build
```

Визуально: страница упражнения с GIF, с 2 фото, с 1 фото, без фото.

## Вне области

- GIF в сетке каталога и в цитатах ассистента.
- Табата-таймер и любые тренировочные сценарии.
- Использование мультиязычных инструкций датасета (у нас уже есть RU-переводы).
- Ручной разбор всех 195 кандидатов — только точечные overrides.
- Хранение бинарников GIF в git (они остаются во внешнем клоне).
