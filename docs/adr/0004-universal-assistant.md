# Универсальный ассистент вместо узкоспециализированного

Промпт «фитнес-ассистент» приводил к отказам на вопросы поддержки вроде «почему не работает авторизация?» («это не по моей части»). Решили сделать одну универсальную личность в обеих вкладках: ассистент вежливо отвечает на любые вопросы, для фитнеса пользуется инструментами каталога, для вопросов о продукте даёт конкретные шаги диагностики, а форматирует ответ без markdown.
