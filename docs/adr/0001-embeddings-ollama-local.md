# Локальные эмбеддинги через Ollama

Для RAG нужны векторы, но DeepSeek (наш LLM) не предоставляет эндпоинт эмбеддингов. Решили считать эмбеддинги локально моделью `qwen3-embedding:0.6b` (1024 измерения) через Ollama: корпус мал, не нужен второй облачный ключ и расходы, данные не покидают машину. Следствие: для сборки индекса и RAG-поиска требуется запущенная Ollama; без неё ассистент работает, но без RAG-контекста, а `npm run index` падает.
