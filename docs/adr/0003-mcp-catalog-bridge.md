# Каталог как отдельный MCP-сервер, бэкенд — MCP-клиент

Ассистенту нужен доступ к данным каталога как к инструментам, а интерфейсу — превью материалов из ответа. Сделали standalone MCP-сервер (streamable HTTP) с инструментами каталога, а чат-бэкенд подключается к нему как MCP-клиент и прокидывает инструменты в tool-calling LLM.

## Considered Options

- **Внутренние функции в бэкенде без MCP** — отвергнуто ради переиспользуемости и стандарта.
