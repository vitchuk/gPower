# Анонимная «Помощь» без сохранения и личные чаты в базе

Поддержка должна быть доступна без входа, но история нужна только постоянным пользователям. Поэтому вкладка «Помощь» — анонимный SSE-эндпоинт, который ничего не пишет в базу (контекст хранится в браузере), а вкладка «Ассистент» ведёт чаты в SQLite под аккаунтом.

## Considered Options

- **Авто-гостевой аккаунт по cookie** — отвергнуто: плодит сущности и мусор в базе ради эфемерной поддержки.
