# SQLite + sqlite-vec на встроенном node:sqlite

Нужен векторный поиск без отдельного сервиса. Выбрали встроенный `node:sqlite` с расширением `sqlite-vec` и одним файлом `data/gpower.db`, чтобы избежать нативных сборок (`better-sqlite3` рискует не собраться на новых версиях Node и в Windows) и нулевой инфраструктуры. Следствия, влияющие на код: PK векторной таблицы `vec0` принимает только BigInt, а `sqlite-vec` (CJS) подключается через `createRequire`.
