# ADR-0008: GIF-медиа Gym visual из внешнего клона, риск лицензии принят

## Контекст

Нужны анимированные демонстрации упражнений на странице упражнения. В каталоге (`free-exercise-db`) только статичные фото. Рассматривались: видео из `amiinwani/free-exercise-db-with-videos` (происхождение видео неизвестно — автор купил набор в рекламе, README предупреждает «use with caution»), платные наборы (Vital Animations, ExerciseDB), горячие ссылки на CDN (хрупко) и датасет `hasaneyldrm/exercises-dataset` (зеркало `Cesarfc206/exercises-dataset`).

## Решение

Использовать GIF из `hasaneyldrm/exercises-dataset` (1324 анимации 180×180) как внешний gitignored-клон `cesar-exercises-dataset/`, по образцу `free-exercise-db/` (ADR-0006): клон не изменяется, обновляется через `git pull`. Сопоставление с нашими упражнениями хранить в `data-aug/media/<id>.json` под версионным контролем; генератор — `npm run media-map`, ручные правки — `overrides.json`.

Осознанно принимаем лицензионный риск: медиа — © Gym visual, репозиторий распространяет его «с разрешения» правообладателя, но прямо указывает, что клонирование не даёт прав третьим лицам. Обязательные условия, которые проект соблюдает: видимая подпись `© Gym visual — https://gymvisual.com/` рядом с каждым GIF, использование только в исходном разрешении 180×180 (без апскейла), отсутствие заявки на права. Датасет выбран вместо `amiinwani`, потому что там хотя бы указан правообладатель и условия; вариант с видео «из рекламы» отвергнут.

## Последствия

- Покрытие неполное: автоматически сопоставлено 224 из 876 упражнений (25.6%); 195 кандидатов ждут ручного разбора через `overrides.json`.
- Для коммерческого использования медиа может потребоваться отдельная лицензия Gym visual; при претензии правообладателя медиа удаляется без изменения остального продукта (маппинг и клон изолированы).
- GIF отдаются локально (`/gifs/*`), без внешних CDN и без хранения бинарников в git.
- При обновлении датасета маппинг пересобирается идемпотентно, каталог и RAG не затрагиваются.
