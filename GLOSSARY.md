# gPower

Каталог упражнений с ИИ-ассистентом поддержки пользователей. Проект существует, чтобы отвечать на вопросы о продукте и подбирать упражнения из каталога, опираясь на документацию, а не на память модели.

## Язык

### Данные

**Упражнение** (Exercise):
Единица каталога: название, мышцы, снаряжение, уровень, техника выполнения и изображения.
_Avoid_: тренировка, задание

**Тренировка** (Workout):
План из нескольких упражнений. В каталоге не представлена — это отдельное будущее понятие, не путать с упражнением.
_Avoid_: упражнение, программа (в значении «одно движение»)

**Датасет** (Dataset):
Внешний публичный набор `free-exercise-db` (876 упражнений), подключаемый клоном репозитория и проектом не изменяемый.
_Avoid_: база, каталог

**Каталог** (Catalog):
Датасет вместе со слоем дополнений: всё, что видит и ищет пользователь.
_Avoid_: датасет, база данных

**Резюме** (Summary):
Сгенерированное описание упражнения на русском и английском, дополняющее исходные данные датасета.
_Avoid_: описание, статья, аннотация

**Слой дополнений** (data-aug):
Версионируемые данные, созданные проектом поверх датасета; сейчас это резюме упражнений.
_Avoid_: датасет, кэш

### Поиск и RAG

**Индекс** (RAG index):
Хранилище документов и эмбеддингов, по которому ассистент ищет релевантную документацию; пересобирается командой `npm run index`.
_Avoid_: база знаний (в значении «весь каталог»)

**Документ** (Document):
Единица индекса — одно упражнение или одно резюме.
_Avoid_: запись, документ (в значении «файл»)

**Гибридный поиск** (Hybrid search):
Способ отбора документов, сочетающий поиск по векторам и по ключевым словам.
_Avoid_: векторный поиск (это лишь половина)

### Ассистент и поддержка

**Ассистент** (Assistant):
ИИ-собеседник gPower, отвечающий на любые вопросы; для вопросов о каталоге пользуется инструментами, а не догадками.
_Avoid_: бот, чат-бот, поддержка (в значении «человек»)

**Цитата** (Citation):
Упражнение, на которое ассистент сослался в ответе; отображается карточкой-превью со ссылкой.
_Avoid_: ссылка, источник

**Инструмент** (Tool):
MCP-инструмент, дающий ассистенту доступ к каталогу (`search_exercises`, `get_exercise`, `get_filters`).
_Avoid_: функция, API

**FAQ**:
Статический список частых вопросов с ответами на вкладке «Помощь»; отвечает без обращения к модели.
_Avoid_: справка, гайд

**Вкладка «Помощь»** (Help):
Чат с ассистентом без входа; контекст диалога живёт только в браузере.
_Avoid_: поддержка, ассистент (как синоним вкладки)

**Вкладка «Ассистент»** (Assistant tab):
Личные чаты пользователя с сохранением истории в базе.
_Avoid_: помощь, чат

### Пользователи

**Пользователь** (User):
Зарегистрированный владелец аккаунта; его чаты сохраняются.
_Avoid_: клиент, аккаунт, юзер

**Гость** (Guest):
Неавторизованный посетитель; пользуется каталогом и вкладкой «Помощь».
_Avoid_: аноним, гость (в значении «пользователь без чатов»)

**История диалога** (History):
Последние сообщения чата, передаваемые ассистенту как контекст.
_Avoid_: память, контекст (в значении «весь диалог»)
